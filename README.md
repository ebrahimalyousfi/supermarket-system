# 🛒 Supermarket Management System

A comprehensive desktop-based **Supermarket Management System** built with **Python** to streamline inventory control, track sales transactions, manage user access, and improve daily operational efficiency for retail stores.

---

## 🔑 Demo Credentials (بيانات الدخول التجريبية)

* **Username:** `admin`
* **Password:** `admin`

---

## ✨ Key Features (المميزات الأساسية)

* **Inventory & Stock Management:** Track products, manage categories, monitor stock levels, and set low-stock alerts.
* **Point of Sale (POS) & Billing:** Quick and efficient checkout process for daily sales and item scanning.
* **User & Role Management:** Secure authentication system with admin access control to safeguard store data.
* **Sales Analytics & Reporting:** Real-time visibility into daily sales, revenue, and product performance.
* **Data Security & Persistence:** Structured local database handling to ensure continuous operation without downtime.

---

## 🛠️ Built With (التقنيات)

* **Language:** Python
* **GUI Framework:** Desktop Application Logic (Tkinter / CustomTkinter)
* **Database:** SQLite / Relational Database
